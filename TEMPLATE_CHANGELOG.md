# Template changelog

Consumers track absorbed changes via `template/v*` tags (see
`TEMPLATE_SYNC.md`).

## template/v1.0.0

- Initial tagged state: GNOME Shell 50/51 ESM skeleton, pure vs GJS module
  architecture, Node built-in test pipeline, ESLint 9 flat config,
  CI (test, release, CodeQL), SonarCloud properties, i18n scaffolding,
  AI-agent tooling, `setup-project.sh`.
- Introduced the template sync convention (`TEMPLATE_SYNC.md`, tags,
  consumer manifest `.template-sync.json`).
